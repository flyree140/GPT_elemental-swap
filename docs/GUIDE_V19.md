## 地圖真的對應角色所在座標

金色箭頭＋光圈＋「你在這裡」繪製在所有地點上方，文字列同時顯示當前地名與 X/Y 世界座標。「定位我」將玩家置中並放大；「全世界」回到 300 地點總覽。拖曳平移、滾輪或 +/− 縮放。

搜尋可找地名、環境或任務。選中地點看環境、研究條件、地方裝備與相鄰通道；「設定步行目標」畫出實際连線路徑。路線可能經過機關，不代表自動通關。尚未抵達的前哨不能透過選中地圖直接快旅。地圖情報與親自發現不同，探索計數只算實際發現。

小地圖用實際地形網格、平台與梯道繪製，顯示角色方向、視野框、元素錨點與導航。墨境有視距限制；墨境羅盤能解霧／指出研究匣方向，遮光鏡也有局部尋匣作用。

## 環境、生態與返程

水域只存在於當地範圍。水下有阻力與氧氣；魚人天然不減速、不需氧氣，潛鐘肺葉停止耗氧但不免深海壓力。壓差背架處理壓力，永久潛鐘提供途中補氧。雪地有滑移與寒冷；沙漠有流沙阻力；磁場、樹脂、洋流、重液與週期環境各自影響移動或戰鬥。

世界不是整張鋪水，也不是掉出地圖再傳送回去。實心底床、坡階與返回梯道保留。普通跨地點維持世界座標，不觸發房間出口傳送；機關守的是獎勵與捷徑，不移除唯一返程底床。元素換位檢查兩端空間、距離與層別，非法落點取消而非送去奇怪的房間；主動快旅才清除舊錨點。

新增五十個原生種，逐一對應五十個領域王；另有四十九個舊種領域王。圖鑑共二百零七條，未見過只顯示未知，不預先揭露名字。已遭遇條目有攻擊方式、反制、材料、相關配方與對應王種。原生種死亡後遊戲內七十五秒重生，玩家仍近距離停留時不貼身刷新；領域王需要在碑座／王庭按 E 主動召喚，死後一百二十秒才可再召。在場的王不會重複生成或重置血量。開選單暫停時不推進恢復計時。

敵人以預告→出手→後搖攻擊；目標落點鎖定後不一直黏著玩家。領域王半血交替兩種攻擊。物種使用十九類共同行為組合，不是每個名字都各有一套完整 AI。

## Z／X 連段與技能節奏

原地按 Z 是快刺、X 是重擊；差異包括命中盒、時間點、段數、破勢值與控制。不要同時狂按兩鍵；先出第一擊，在約 1.05 秒內接續，動作末段能預先輸入下一鍵。

| 指令 | 真正作用 |
|---|---|
| ZZZ | 三次独立定點連刺，不強迫移動 |
| XZ | 只回拉敵人到身前，適合元素場 |
| ZZX | 挑高普通敵人；頭目改破勢／短失衡 |
| XXZ | 四秒破甲並大幅削 BREAK |
| ZXX | 1.8 秒釘地，頭目短暫受控 |
| XZX | 0.5 秒正面架刃，反彈一枚敵彈 |
| ZXZ | 左右兩側環斬，角色不穿身 |
| ZZXX | 把浮空敵人壓回地面，玩家不強制下墜 |

90 技能基礎冷卻介於 1.15–4.8 秒；多數短招 1.15–3.4 秒，持續區域約 3.2–4.8 秒。命中普攻只縮短最久的一個配裝技能：單／雙鍵招 0.16 秒、三鍵以上招 0.42 秒，0.24 秒內最多一次；群怪、多段不無限疊加，揮空不回復。

十五職仍各六招、帶五招。短按與長按是同一招的不同施作方式，沒有同鍵追擊暗中換招。招式清單與基礎冷卻見 SKILL_CATALOG.md。

例：織夢潛行者用夢偶引怪、夢種安眠、收割消耗困意。X／Z 職業困意被動與公共連段可配合，但持續火雷傷害仍會喚醒睡眠，並非任何效果都無條件加成。XZ 拉回 → ZXX 釘地 → 雷線／織夢庭院，是先定位再放場域的路線。

## 保留九規則與四層元素

既視感保留三秒路徑踏點與原座標攻擊重播。過去恢復指定舊橋；大重力影響落下與落地震波；向量反轉速度與場域推拉；彈力提供回彈，↓ 止彈；真菌生成菌台；裏／表切換指定牆、路徑與層別；未來啟動機械與升降台；崩壞逐步移除指定高台，回當下即恢复，實心底床保留。它們是同一張地圖的結構／物理狀態，不是多套獨立故事世界。

十元素 LV1–LV4 每層 A／B 互斥，跨層疊加。例：雷 A／B／B／A 是雷線＋導電跳鏈＋攔彈電網＋留場雷痕。既有場域保留建立時的配裝快照，修改分支影響下一次換位。水冰橋、火水蒸汽等既有反應保留；這是碰撞與局部場域，不是完整流體模擬。
