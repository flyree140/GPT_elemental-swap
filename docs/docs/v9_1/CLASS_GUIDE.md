# 八職業差異

## 裂隙劍士

- 快速貼身與穿身 Command。
- 命中可刷新空中 Dash。
- C 用於取消與換側；V 追空；B 多段閃滅。
- 適合把元素錨點插入近戰 Combo。

## 靈契召喚師

- Z：短杖近戰。
- X：召喚／指令分支。
- 狐狸、鴞與守護靈同類最多一隻。
- 再次召喚不增加數量，而是刷新時間與 Rank。

## 森靈德魯伊

- 狼：小 Hitbox、地面速度快、取消早。
- 鷹：落速低、空中攻擊強、上升能力多。
- 熊：Hitbox 大、霸體、高 KD 與高 BREAK。
- Q 在三形態間切換；B 进入森王變身。

## 符機工匠

- Z：扳手近戰。
- X：慢速齒輪彈，能和它一起換位。
- 炮台同時提供遠程壓力與空間控制。
- 躍台和鉤索是主要位移技能。

## 磁軌槍手

- 所有射擊都有後座位移。
- 投射物刻意慢，玩家可追著子彈走、跳或換位。
- 適合在空中用反向後座修正位置。

## 界壁守衛

- Z：長槍。
- X：盾擊與格擋分支。
- 精準格擋可取消傷害並立即反擊。
- 高 BREAK，適合 Boss 失衡流程。

## 時序術士

- Command 留下延遲回響。
- 凝滯場降低敵人與投射物速度。
- 時間錨與三秒回溯可修正失誤、返回舊位置。

## 鎖鏈游擊者

- Z：近身踢擊。
- X：鎖鏈抓取。
- 輕型敵人被拉來；重型敵人拉不動時，角色反而被拉向目標。
- 適合在房間上下兩層之間持續換側。
