# V9 地圖設計｜有機互聯，而非規則高樓

## 設計原則

V9 的垂直不是「把平台每隔固定高度排一層」，而是：

1. 房間本身可高可低、寬窄不同。
2. 直井把多個高度串起來。
3. 高處經由落差回到舊區，形成單向回環。
4. 元素能力門讓玩家日後回頭打開新路。
5. 避難所是導航、補給、教學和快速移動節點。
6. 隱藏房不直接放在主線旁，必須解謎或從另一區繞入。

## 房間種類

- `shelter`：家具、NPC、存檔與快速移動。
- `shaft`：牆跳、梯子、抓鉤、慢速彈換位的長垂直段。
- `hub`：三條以上路線相交的導航房。
- `cave`：不規則洞穴和低矮支路。
- `facility`：機關、移動物件和多層工業空間。
- `outdoor`：樹冠、月橋和風場。
- `secret`：能力門、功能神殿與故事收藏。
- `boss`：Break 與多階段競技場。

## 有機世界圖

`js/world.js` 定義：

- `rooms`：房間的座標、尺寸、類型和區域。
- `edges`：房間之間的連線與能力門。
- `shelters`：快速移動節點。
- `collectibles`：功能神殿。
- `puzzles`：多元素解謎。

要新增房間時，不必把整張地圖改成規則網格。只需新增房間、連線，再在 `game.js` 的房型生成器補充地形配置。
