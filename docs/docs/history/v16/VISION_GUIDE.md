# V16 視界實際遊玩指南

這份文件描述本 ZIP 中的實作，不是上一份尚未實裝的設計提案。

## 進入方式與配裝

按 J，從八個可配裝視界中選兩個。當下 B 層永遠保留，不占槽。按 [ 或 ] 直達該槽；按 \ 回到當下。原本 Z/X、C/V/B、Q 與 1–0 完整保留。

切換不扣 MP／能量。鏡系分支 A/B 可免費切换；舊職業技能強化仍使用原本永久專精點。切換時的短冷卻按視界分別記錄，換槽不會把已有冷卻清空。

| 視界 | 切入冷卻 | 主要限制 |
|---|---:|---|
| 既視感 | 3.5s | 同時一個殘影；需要先有行動記錄 |
| 先知 | 0.35s | 只能干預菱形結點，不能把整場 Boss 攻擊全部刪掉 |
| 低熵 | 3.8s | 局部、有限持續時間；解凍敵彈仍敵對 |
| 超熱 | 0.4s | 只改蜂巢門、回彈樑等指定材料 |
| 宏觀／微觀 | 0.4s | 指定配重／晶格才接受轉態 |
| A / C | 0.32s | 目的地必須有合法空間，另一層也可能有攻擊 |

## 01 鐘錶回廊：把空揮變成伏擊

1. 先移動、起跳，揮 Z、ZZX 或 C 技能，留下約一至三秒紀錄。
2. 按 [ 既視感，出現琥珀殘影與腳底光軌。
3. 殘影在原位置、原時間節奏回放攻擊；它不會跟隨現在的敵人。
4. 可先站在想要放置敵人的位置，對敵人發射元素標記，再按同元素鍵把敵人換進刀路。
5. 起跳再切既視感，實際落在金色光軌上，完成課程。

紀錄包含角色姿態、近戰有效攻擊框、範圍脈衝與投射物事件。一般空揮也會紀錄。回放時才進行一次新的命中檢查，而不是照抄上次傷害。

不重複施放治療、召喚物生成、掉落、技能冷卻重置等副作用。召喚物自身不再複製一份；殘影也不能再錄出殘影。不是 120 招全部副作用的精確複製器。

換位、重生或跨層的位置不連成橋。光軌穿入現有實體平台的片段不建立碰撞。A 分支光軌 6 秒／回放傷害 42%；B 分支光軌 4.5 秒／回放傷害 50%。

## 02 預射觀測室：射掉一枚未來攻擊

按 [ 切先知。背景降低飽和，但角色、平台頂邊及 HUD 保留清楚色彩。

**實線**來自已鎖定的攻擊計畫或已發射彈體；**虛線**是未承諾的可能方向。菱形才是可射擊的因果結點。

守衛每次先鎖定，再延遲發射。朝菱形射 1–0，或使用有投射物的職業技能；子彈真正碰到結點，就取消對應 plan ID 或現存敵彈。這一枚不會在倒數後再次生成。

干預後附近守衛暴露 3 秒；在這段時間實際命中，完成第三項條件。

兩秒預測沒有承諾所有原有 AI 未來的隨機選擇。新教場與帕拉克斯使用可驗證的鎖定 plan；舊敵人主要對既有投射物做軌跡預覽。不是盲目把人物朝向乘速度後就稱為確定未來。

## 03 冷凝泵站：把彈幕做成路

等待守衛四枚慢彈出現，再按 [ 低熵。

- 敵彈停住，生命時間也停止倒數。
- 玩家、新發射的元素彈、職業技能冷卻照常運作。
- 凝結敵彈下緣生成 70px 的實際平台。
- 對凍彈射元素，形成對應標記；再按同元素鍵換位。
- 換位後原元素效果仍會出現：火是雙火區、冰是冰台、水是噴泉等。

A 分支凝結 3.6 秒；B 為 3 秒，強化解凍衝量。到期前 0.7 秒顏色改為警示黃，恢復前另有短暖機時間。停住不等於反射成友軍；要反射仍需原本 A 借力能力。

低熵也使附近熔岩表層／水柱固化、停止閘門機構；凝結的普通敵人只短停 1.5 秒，不永久鎖死。敵人被擊退時儲存有限衝量；改用 ] 超熱會提前解凍、釋放衝量並形成破甲。

右側蜂巢門只有超熱可穿。回彈樑可以把角色或敵人彈回；不是全圖所有牆都忽然有彈性。超熱會讓附近冰台進入一秒融解警示。

## 04 晶格搬運站：宏觀負載／微觀通路

[ 宏觀：鏡頭縮到 0.74，玩家跳躍重力不變；對重型箱射 4 風、5 岩或 0 引力，箱子實際受力。推到插槽會新增回程踏台並保存開啟狀態。

] 微觀：玩家碰撞尺寸變成原本 0.48，鏡頭放大到 1.24，敌方運動減慢。晶格牆底部露出 46px 空間，必須用小身形實際穿過。

毒池上方的分子球在微觀才有平台碰撞。跳上任一分子踏點完成驗證；毒池本身仍危險。

縮放不是任意穿牆。恢復體型或換層時，若小範圍內沒有足夠空間，原地保留目前模式，顯示取消原因，不扣切換冷卻。

## 05 三層觀測塔：同座標不同切片

- 當下及其他非切片模式視為 B。
- [ A：B 高牆成為虛線投影，A 管線踏台成為實體。
- ] C：C 的高台成為實體；B 守衛只顯示異層輪廓。
- C 中普通攻擊打不到 B。用 7 光命中 B 守衛，可建立有期限的光接點。
- 影元素錨點允許跨層找回；其他錨點仍需位於可達切片。

子彈、砲台與火區保留產生時的層，不會因玩家切 C 就整批搬進 C。跟隨玩家的契靈則隨玩家調整所在層。

有 B/C 標示的射線只傷該層；ALL 疊層紅框會傷所有層。教場也會交替安排 C 射線。在原有普通戰鬥房停留於 A/C，附近有敵人時會出現同層掃描預警，因此非基準層不是永久無敵。

## 06 因果織機・帕拉克斯

J 可以直接進正式 Boss 試煉。沿用哨兵造型，以雙層核心環區別新 Boss；AI 與攻擊排程是 V16 新實作，不是只有改名字。

HP 1850、BREAK 360。第一階段安排可干預慢彈與 B 攻擊；67% 以下啟用冷凝外殼，光命中或 BREAK 打開弱點；34% 以下加入 ALL 掃描／範圍攻擊。

一般無連結攻擊對第二階段外殼只造成部分傷害。BREAK 中可攻擊，也可以真正交換 Boss 位置；未失衡的大核心禁止搬動，會說明原因。

原赫利俄斯與東境監察者的存在、血量與通關旗標不被替換。帕拉克斯首次击破 +6 專精點；五個教場首次完成各 +3，重复完成不洗點數。

## 交會：讓本體、殘影與契靈合作

同一敵人在 0.55 秒內被兩種來源先後命中，會開出交會窗口並給一次空中 Dash。每 0.8 秒最多一次；單純反覆切鏡不加分，也不重置所有技能。

劍士可先留斬擊，再把敵人換進殘影刀路；召喚師可先讓狐狸命中，再接本體；槍手可預射慢彈、干預結點、換位追擊。原本六槽與同鍵追擊仍在 L 工坊設定。
