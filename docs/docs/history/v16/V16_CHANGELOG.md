## 本輪開發中實際找到並修正的問題

1. 凝結敵彈的平台比彈體寬，原先會先擋住玩家的標記彈。現在平台與彈體共同接受標記。
2. 玩家換層後，舊元素彈／技能彈原先可能被錯層目標消耗。現在依出生層分組更新。
3. 地面火區與噴泉原先容易隨當前視界一起換層。現在保留出生層，傷害、推力與平台碰撞一致。
4. 跨層光命中必須讓後續技能也能打到，而非只讓光彈自己造成傷害。光接點現在持續3或5秒。
5. 第二階段 Boss 尚未建立 linkUntil 時，undefined 比較可能跳過減傷。改為顯式有效時間判斷。
6. 冷凝水柱的碰撞生成晚於安全落點檢查，可能把玩家關在柱內。現在先預覽即將生成的碰撞再切換。
7. 原世界切 A/C 不能成為永久免疫；新增有清楚延遲預警的同層觀測掃描。
8. 視界按鍵在 hit-stop 期間也要處理，避免輸入被原 loop 清掉。
9. 宏觀插槽不能只亮燈；成功搬運會新增兩片回程平台並保存解鎖。
10. 正式 Boss 的新擊破旗標不可覆蓋原赫利俄斯通關旗標，分開儲存並去重獎勵。
