# V11.0.0｜歸燈聚落

## 保留

V10 的 world.js、game.js、skills.js、mastery.js、network.js 和原 assets 完整逐位元保留。config.js 只更新版本字串。78 房、120 招、十職教學與原敵人／Boss 不刪減。舊住區外的畫風與平台設計不重置。

## 美術

新增 18 個與實際樓板對齊的剖面建築 PNG、18 個生活家具 Sprite、3 個局部環境背景。暖室／冷外景、屋頂太陽能、天線、水箱、窗框、垂掛植物、餐具、工具、手記、管線與病房佈置。物件不用圖片上的文字當可操作提示；名稱與 E 指示由遊戲即時繪製。

海崖初始避難所偏青綠日光；懸掛聚落是森林中錯層住屋；鐘錶工坊是藍色月夜與暖室。18 處重做的是既有避難所，不是加十八棟規律塔樓。

## 生活系統

192 件互動家具、18 種功能；新增可鍵盤操作的服務面板／U 日誌。水→雷修機組、自然催苗、收香草煮湯、收藏陳列、有限回收、床位重生、星圖記錄、實體捷徑。

## 保存與公平性

`progress.haven11` 使用原 V10 save key。一次性獎勵獨立 key，不使用只存在記憶體的 furniture.used。補給／採收計時基於累計遊戲秒數，暫停不增加。禁止遠端執行家具操作。快速移動不解鎖尚未抵達地點。

## 拍照與介面

I 切換觀景，鏡頭對準整間避難所。原平台／技能／敵人仍然運作。避難所中減少 HUD 壓迫，物件面板使用暖米色高對比字體。首次載入若缺少程式，入口會顯示「請完整解壓或開 PLAY_OFFLINE.html」，不再無聲白屏。

## 範圍限制

本次不是多人網路層或整體平衡大改，也沒有實作使用者 GDD 的時間世界切換。完整性指的是交付含全部現有程式／圖像並可啟動部署，不代表商業成品或完成所有未來提案。
