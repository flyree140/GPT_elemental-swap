# 十元素效果與解謎

| 元素 | 命中效果 | 換位效果 | 解謎用途 |
|---|---|---|---|
| 火 | 燃燒 DOT | 新舊位置雙火區 | 點燈、燒毒池、熱震 |
| 冰 | 冰緩／濕潤時凍結 | 生成可碰撞冰台 | 凍水、建立臨時落腳點 |
| 雷 | 暈眩／濕潤增傷 | 新舊位置鏈雷 | 水雷電路 |
| 風 | 大擊退 | 風衝與低重力 | 推箱、啟動風井 |
| 岩 | 破甲、高 BREAK | 生成石柱 | 重量、破裂結構 |
| 水 | 濕潤、熄火 | 噴泉與治療 | 火牆、導電、生長 |
| 光 | 顯形、清詛咒 | 護盾與顯橋 | 光橋、暗室、隱藏房 |
| 影 | 詛咒 | 相位與誘餌 | 穿影門、繞背 |
| 自然 | 纏根 | 可攀藤柱 | 古種、樹橋、生長序列 |
| 引力 | 飛行中吸怪／箱子 | 持續引力井 | 核心球、遠距搬運 |

## 元素連鎖

- 冰 → 火：熱震。
- 水 → 雷：導電暴潮。
- 火 → 風：烈風火環。
- 岩 → 自然：岩根隆起。
- 光 ↔ 影：明暗蝕相。
- 引力 → 風：引力彈弓。

## 換位安全落點

換位不直接把玩家中心塞到投射物中心。`findSafePosition()` 會：

1. 嘗試目標附近的平台上表面。
2. 排除實心碰撞內部。
3. 檢查世界邊界。
4. 找不到安全點時回退到鄰近可站位置。

因此第一次換位不應再穿到平台下方死亡。
