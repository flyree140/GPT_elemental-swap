# V18 完整遊玩手冊｜澄界・連續世界

## 01 第一次玩：先看見結果，再疊系統

從海崖避難所出發。頂部「教學 H」可查看控制與概念；「職業研習 T」選目前職業或任一職業。安全實作庭借用五格技能與雷元素，敵人是可承受狀態的練習靶；不消耗探索裝備。每步看上方目標，實際完成才會往下一步，不是一直按下一頁。

先做八階入門：步行、跳躍、Z 命中、X 命中、C 短／長按、雷換位、空中路徑既視感、Q。十五職業各有六階研習：近戰、第一招短按、同招長按、該職業特有組合、Q、元素與規則。九規則也各有「切换／觀察物理／返回」三階課程。

按「返回探索」還原原職業、背包配置與原位置。教學內自動儲存與匯出使用的是进入之前的探索狀態，不是借來的技能。研習不是傳送到正式關卡去送死。

## 02 地形與鏡頭：沒有全圖水帶

普通過區只是沿世界座標走過，不會在邊界重建整張場景或清除雷錨。圖上的線是實際挖出的通道；斜坡用小階梯及梯道連接，高低地層都能站立。M 可看 125 個地點、155 段連續步道。48 遠征地點散布於八組環境；舊分離式教室合併為實作庭。

下方不再有橫跨所有環境的水帶，不再把「不會摔死」理解成「掉下去後等救援」。依然可以從高台落到較低地層，也會因敵人、岩漿、缺氧等失去生命；差別是下方不是無底虛空。相機追蹤上下左右，不鎖死在上一間房。

O 的世界遠征及 M 的前哨按鈕是**明確主動旅行**；它與走過邊界不同。主動旅行會清除舊元素錨、投射物、施放暫存及既視感歷史，避免從遠方換回已離開的區域。地形與機關仍有探索限制，不能用任何換位無條件穿過鎖門。

## 03 交換與非法落點

數字 1–0 依序為火、冰、雷、風、岩、水、光、影、自然、引力。第一次射出對應元素，第二次同鍵尋找有效敵人標記或自己的錨點。兩端要有容得下角色／目標的空間、在距離內、層別相容，並通過機關檢查。

交換的是兩個實際世界位置，不是房間內的百分比座標。落點太貼牆時只做小幅局部修正；無法成立則取消並提示，不把玩家搬去另一個房間。失效錨點會退休，讓下次按鍵能重新發射，而非永遠卡在嘗試同一個非法點。普通跨區時未過期的錨點不會因房間 ID 改變而跳位。

## 04 近戰、五技能、蓄力

Z 是輕近戰，X 是重近戰。職業不再向普攻暗加前衝、後退、射擊或自動穿身。放開方向鍵出手可原地打；按住方向仍是玩家自己選擇的移動。空中攻擊沿原本運動軌跡，不代表按 Z 就能停止重力。

C／V／B／N／F 永遠對應畫面上的五招。L 選一招，再點上方槽位換装，每職六招選五招。Q 是另外一個獨立職業機構，不占技能格。没有追擊技能替換，连续按 C 不會變成 D 招。

技能在**放開**時施放。一般蓄滿門檻 0.65 秒，星軌狙擊 0.9 秒；技能卡會顯示精確時間。按住時可看準星／部署位置、進度和將施放的名稱，蓄滿改成金色。短按與長按是同一招的兩種用途，共用冷卻，不是無腦多按一定更強。跳躍、衝刺、開選單、視窗失焦及觸控取消會取消準備，不應誤出招。

需要前置物件時會說明「先放夢偶」「先設兩個圖釘」「先鉤住敵人」；失敗不扣該技能冷卻。專精 A 是控制延長，B 是指定範圍／部署距離延伸；它們是通用強化，職業差異主要来自技能本身，不以兩個泛用分支冒充 15 種玩法。

## 05 十五職業：先學一條明確操作循環

### 01 裂隙劍士｜刻痕 → 收束

Z 命中刻下裂痕，最多三層；技能消耗裂痕開路，不再普攻自動穿身。

Q：封刃：下一次普攻的水平推力歸零。

**實作：刻痕不是裝飾。** 先用 Z 或 C 刻出裂痕，再短按 N「合縫收割」。沒有裂痕時只提示，不扣冷卻。

### 02 靈契召喚師｜部署 → 指揮

召喚物留場、選目標、主僕換位。主人的 Z/X 仍為原地杖擊。

Q：集火：命令契靈攻擊瞄準的敵人。

**實作：主人指定，契靈出手。** 先短按 C 召狐，再長按 C 召梟（冷卻後）。按方向瞄準靶子，短按 V「契約集火」。確認契靈從自身所在位置攻擊。

### 03 森靈德魯伊｜三形 → 本能

狼以短爪累積獵痕；鷹空戰；熊抗推。三形是不同身體，不是換色劍士。

Q：輪換狼／鷹／熊，不自動攻擊。

**實作：三形改變身體。** 短按 V 展翼，觀察自己主動升空；落地後短按 B 變成熊並震掌。Q 輪換形態本身不攻擊。

### 04 符機工匠｜雙炮 → 連線

最多兩座炮台。連線、改向、拆解是主要玩法；X 改回扳手重敲。

Q：切換炮台：射擊／攔彈。

**實作：先有雙端，再有纜線。** 短按 C 放第一炮台，走開約 150px，等冷卻後再短按 C 放第二炮台。短按 V 通電。長按 V 則只要一座炮台，另一端連向自己。

### 05 磁軌槍手｜裝填 → 彈種

四枚重彈；短按裝普通彈、長按裝破甲彈。射擊短按貫穿、長按散射。Z/X 是槍托，不發射。

Q：快速裝填兩枚；不能超過四枚。

**實作：彈種和射法分開。** 長按 V「戰術裝填」放開，裝滿四枚破甲重彈。接著短按 C 是貫穿；長按 C 是散射。Z／X 永遠只是槍托。

### 06 界壁守衛｜格擋 → 破勢

格擋累積守勢；釋放時才打斷敵人。長按有盾面預覽，角色不前衝。

Q：精準格擋 0.6 秒；成功獲一層守勢。

**實作：防守不是自動突進。** 短按 C 架設固定盾面；等練習彈撞盾。攔彈會積累守勢；短按 B 才主動把守勢變成衝擊。

### 07 時序術士｜記錄 → 時債

記錄與返回是兩個明確按鍵；延遲傷害不複製掉落或重置敵人生命。

Q：暫緩近身敵彈 1 秒，不讓玩家傳送。

**實作：明確的記錄與返回。** 短按 C 留時錨，走離 120px 以上，再短按 N「返回時錨」。它是回到記錄座標，不重置怪物、場景或掉落。

### 08 鎖鏈游擊者｜拉怪 ≠ 拉己

拉怪與拉自己分成兩招；鎖在兩個實際世界座標之間。

Q：解除所有繩索；不自動拉人。

**實作：拉怪，和拉自己，是兩個鍵。** 先用 C 鉤住前方練習靶（自己不位移）。再按 V 沿索突進，這次才是角色主動移動。沒有鉤住敵人時 V 只提示。

### 09 化學調律師｜選劑 → 觸媒

Q 輪換水／火／雷試劑；投瓶、觸媒與回收分工。X 改回原地短杖。

Q：輪換水 → 火 → 雷試劑。

**實作：試劑不是單色傷害。** Q 選水試劑，向右上長按 C 投瓶。落地產生水場後，Q 輪換到火，短按 V「觸媒攪拌」；近處異元素場會產生蒸汽。

### 10 雷影武僧｜交替 → 氣息

交替 Z/X 命中累積氣息；同鍵不再觸發另一技能。

Q：0.6 秒反掌窗口，成功格擋回復一層氣息。

**實作：氣穴需要後續命中。** 走近靶子短按 B「點穴指」，再用 X 命中。同一技能不會偷換成下一招，X 是你明確發出的命令。

### 11 星軌狙擊師｜測距 → 狙擊

站定會累積專注。真正的精準射擊在 C；Z/X 只做原地近戰。

Q：穩息：立即消除水平慣性，3 秒內加快站定專注。

**實作：真正的狙擊在技能槽。** 短按 V 為前方靶子留下弱點，站定積累專注。按住 C 看長距離射線，蓄滿放開可貫穿多個目標。距離和擋路的實體地形都會影響射線。

### 12 縫界傀儡師｜傀儡 → 提線

先放傀儡，再操控它攻擊或與它換位。沒有傀儡會清楚提示。

Q：命令傀儡回到身旁，不造成傷害。

**實作：斬擊從傀儡出發。** 長按 C 將傀儡放在靶子附近，自己可以站得較遠。短按 B「提線斬」，觀察攻擊從傀儡所在位置發出，不是玩家周圍再畫一個圈。

### 13 折境製圖師｜雙點 → 橋門

先設定原點 C，再設定終點 V。橋與門都使用這兩個世界座標。

Q：清除兩枚圖釘；不觸發換位。

**實作：兩個世界座標是一座橋。** 短按 C 設原點；往右走至少 180px，短按 V 設終點，再短按 N「繪製棧橋」。橋依照兩圖釘的真實座標生成；開門則要 B 後在門邊 E。

### 14 荒野食契師｜火候 → 料理

Z/X 命中累積火候，料理和收鍋使用火候；沒有食材也能普攻。

Q：調火：下一次鍋爐選燉煮／煎烤。

**實作：爐具要放對地方。** 短按 V 放火爐，長按 V 則放水鍋。短按 N 引爆已有爐具；長按 N 是收回，不會爆炸。Q 另切換下一鍋燉煮／煎烤。

### 15 織夢潛行者｜困意 → 收割

Z 命中加一層困意（最多三層）；X 命中三層者使其入睡。傷害會喚醒。

Q：夢視：顯示困意與安眠倒數，延長困意 3 秒。

**實作：安眠 → 收割，不要先把夢打醒。** 靠近靶子，短按 C 在腳前埋夢種，靶子進圈後會安眠。趁睡眠存在短按 N「夢魘收割」。火／雷持續傷害會提早喚醒，先別疊傷害場。

## 06 你的九種世界規則

J 中可直接切換，也可裝到 [ 與 ] 兩格。反斜線返回當下／表世界。同時只生效一種規則；種族、職業和元素仍保留。選單中時間暫停。世界切換不回復敵人 HP、不重領掉落。

### A 既視感

最近 3 秒的路徑變踏點；一個殘影按原時間、原位置重播攻擊。

不追蹤敵人；換位／重生不連成橋；不複製召喚物、治療或獎勵。

### B 過去世界

斷裂的舊橋恢復、舊式機械門封閉；同一座標走另一條路。

不回復敵人 HP、不重領素材；切回時需有安全空間。

### C 大重力世界

角色、敵人、投射物與箱子承受 2.15 倍重力；高速落地產生震波。

跳躍變矮，羽族與風柱仍能抵銷一部分；底床不崩落。

### D 向量反轉

切入與切出各反轉一次所有活動物體的速度；場域拉力／推力相反。

方向鍵不反轉；不改換位座標。靜止物體不會被憑空加速。

### E 彈力世界

落地、碰牆與投射物碰撞產生回彈，連跳可到達高台。

按住 ↓ 停止角色回彈；低速著地不自動彈跳。

### F 真菌世界

腳步附近長出蘑菇踏台；菌床傳播緩速與困意。水催生，火使其枯萎。

只改附近生態，底床不消失；孢子不會隔空全圖生效。

### G 裏／表世界

同座標切到裏層：穿過標示表層牆，站上裏層橋；各層敵人不同。

光可跨層命中；裏層有自身脈衝，不是永久無敵。再按即回表層。

### H 未來世界

腐朽門鏽解，未來升降台運行、巨藤長成新路。

機關聯鎖不會被跳過；不洗掉敵人狀態或重置掉落。

### I 崩壞消逝

可崩壞的高台與牆由近到遠在 3–9 秒內消散；切回立即重建。

實體底床永遠保留。站在高台可隨消逝降至較低地形，不墜出世界。

**既視感的踏點不是地毯。** 原版只在沒有與現成地板重疊的空中路徑生成可站點；先走、跳並空中攻擊，再切換最明顯。殘影不追蹤怪，怪走開可以打空。原 A 為踏點 6 秒／回聲 42%，B 為 4.5 秒／50%。

**過去、未來、裏世界的範圍。** 這是同一張地圖上的實體結構／環境狀態：舊橋、機台、層牆、旁路、部分海水高度與景深變化。不是三張各自擁有完整 NPC 時間線與獨立故事的世界。原地形位置保持一致，因此能用橋、圖釘與升降台組合。

**向量反轉。** 進入／離開各反轉當下活動物體的速度，力場拉推方向反轉；不是把左右鍵永久顛倒，也不是把靜止的物體突然加速。大重力的落地震波需有下落速度。彈力按住 ↓ 可止彈；低矮處不會無限狂跳。

**崩壞仍保留底床。** 可崩壞高台逐步不承重，裝飾淡出；返回立即恢復。它不是删除整个地图然后触发救援，也不重建怪物和物品。

## 07 十元素四層成長：每層只選一邊，層與層相加

O → 元素分支。升級耗點依序 1／2／3／4，四級總共 10 點。每個元素各自升級，A/B 可免費重新配裝。LV1 形態、LV2 延伸、LV3 交互、LV4 餘效全部保留，不是升級後覆蓋前級。已放出的場域保存施放當時的分支快照，改配裝影響下一次換位。

## 08 四個可以照做的組合

**夢偶 → 夢種 → 收割。** 織夢潛行者 V 把夢偶放在夢種附近引怪，C 讓進圈者睡眠，N 消耗困意收割。角色不會因為再次按 C 自動換招。火雷持續傷害會喚醒敵人；想長睡，不要先鋪傷害場。

**水 → 雷線 → 狙擊。** 水命中造成濕潤，雷 LV1 A 建兩端線、LV2 B 跳鏈濕敵、LV3 B 至多截三彈、LV4 A 留餘電。再用星軌狙擊師測距、站定專注、長按 C 貫穿。不是元素相加就必定所有敵人都被擊中，場域位置與狙擊線仍重要。

**過去橋 → 圖釘 → 未來升降。** 先利用過去橋找到站位，製圖師 C 設 A 点、V 設 B 點，N 畫橋。B 是開門，再到門邊 E 使用；兩個技能不同。切未來再利用升降台進更高處。機關限制會檢查整條交換／門路徑。

**重力落地 → 彈力反躍。** 大重力使角色跳得較低、落得更快，達速度條件落地產生震波。再選彈力跳回高處，按 ↓ 停彈。魚人改善水下行動、岩裔抗推等種族特性獨立於職業，但不会讓所有關隘都失去意義。

## 09 保留的避難所與成長循環

十五種族、武器／防具／工具、素材、製作、遭遇圖鑑、原有怪物與 V17 新生態仍保留。O 製作可查看材料與裝備欄；八組遠征的環境關隘需檢查相應工具、種族或開關。生態圖鑑在實際遭遇後解鎖，收集素材推動製作。重生與各項冷卻使用遊戲內時間，選單暫停不讓環境偷偷把角色扣死。

水域有限範圍，潛水仍有氧氣与水阻力；深海還有壓力。↑ 游泳，找水面／氣泡補氧，或選魚人／製作相應工具。因為不再有全圖水帶，不代表移除了水域與生物。

## 10 手機、存檔、常見狀況

切手機模式後，左側方向、右側 Z/X／跳躍／衝刺，五招與十元素分别排開。技能長按与键盘相同，手指放开才施放；因系统中断的取消不是短按。四種尺寸和 Chromium 觸控事件已測，實體 iOS／Android 及 Safari 未實測。

L 可匯出存檔 JSON；先匯出 V17，再替換網站檔案。V18 會從舊結構遷移，保留舊儲存備份並退款已退休技能；五槽換成新合法技能。匯入自己的合法存檔後重新載入；不要匯入來路不明檔案。清除網站資料會刪本機進度，雲端帳號同步未加入。

技能沒出手：確認有**放開**按鍵、冷卻完成、物件與資源前置條件成立，並沒有在準備時跳躍／衝刺／開選單。看施放卡或提示，不是靠特效猜招。

換位被拒絕：檢查距離、層別、兩端空間及鎖門。不要連按到误認為世界在跳動；非法錨點退休後重發一顆。想離開水域則上游／找梯道，不需等隱藏救援。
