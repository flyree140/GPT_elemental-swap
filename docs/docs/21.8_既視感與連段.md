# 21.8 開發補充：既視感與指令連段

這份文件取代舊手冊中對既視感與 ZX 節奏的描述；其他世界、地圖、裝備、第一層流派分支、存檔與編輯器維持原架構。

## 檔案

`data/atlas217_config.js` 為版本 21.8.0 的資料，檔名不改以保留原編輯器；`js/resonance218.js` 最後載入，集中控制回放、動作分支與戰鬥 HUD。`js/atlas217_core.js` 負責資料驗證與技能倍率上下文，`js/entropy216_combat.js` / `js/renewal_combat.js` 的記錄位置補齊二次攻擊和場域節點，`js/vision.js` 將回放交給唯一的新計時器。

## 三秒記錄窗

事件包含 `at`、`seq`、`epoch`、`kind`、`layer`、`room`、朝向及原位幾何資料。`epoch` 在重生、暫態重置及有效設定套用後更新，清除舊片段。記錄僅按時間移除舊資料，不以 48 筆或固定短陣列截斷。

主要種類為 `command`、`skill`、`swap`、`box`、`circle`、`line18`、`projectile`、`target`、`field`。`target` 用於結算或 DOT 這類本來就是直接目標的傷害，仍檢查目標是否在原事件位置，並不追蹤已離開該範圍的敵人。

原始攻擊幾何優先擁有自己的記錄；內部逐目標扣血不再另記一次，防止回放雙算。多段招則每段都有一個獨立攻擊事件。具有 `echo: true` 的「玩家擁有的次級攻擊」不等於既視殘影：真正回放以 `_vReplay` 隔離。

F 建立過去三秒的深拷貝快照。日誌包含原始全身姿勢與換位前後位置；換位後取樣具有 `cut`，不跨該節點插值。回放只重演影子，不呼叫玩家的即時 swap/cast 函式。

`cause218` 將已起手的 command / skill 與延遲命中對應。快照只跟隨其中已包含的招式，之後無關的新技能不會混進同一殘影。尚未完成的原招判定可使回放尾端稍延長；場域每跳傷害標記 `fieldTick218`，不因此生成新一輪完整場域。投射物具有自己的有限壽命，身影消散後仍可完成飛行。

回放傷害係數為 0.4，不重新套一遍已錄製的技能倍率。目標當前防禦、破甲與等級等規則仍經既有傷害管線，因此不要把顯示總傷害誤解為不受目標狀態影響的常數。回放不重新套用會造成新增 DOT／連鎖的舊元素狀態處理。

## 指令資料

每招仍使用 width、height、offsetY、damage、duration、pulses、cancel、knockX、knockY、break、clip 等既有欄位。可選的 `action218` 包含：

| 欄位 | 作用 |
|---|---|
| travel / moveFrom / moveTo | 在指定秒數區間以一般碰撞位移，單位為世界像素／秒數 |
| rise | 起手向上速度，必須為負值 |
| dive | 空中下墜速度；低空落地會結算未完成的命中 |
| hover | 很短的留空窗口，不重置跳躍或換位資源 |
| launcher | 上挑用途標記 |
| finisher | 收尾標記，保留專用收招窗口 |
| bounce | 一次浮空循環內最多安排一次彈地 |

`ES217.validate()` 檢查位移上下限、時間區間、脈衝先後及取消時刻、clip 與布林欄位。F9 完整 JSON 或原始 data 可以編輯這些欄位；獨立 editor.html 的基本欄位表不提供所有新動作的專用滑桿。

輸入保存當下方向與按鍵，最多三次先進先出。基礎期限 0.28 秒，排在後面的輸入每個位置增加 0.10 秒容忍；仍會過期，不是自動永久連擊。接段間隔 0.85 秒。世界重置、成功換位、成功技能與流派切換會清除過期連段上下文。

一般敵人有限命中停頓、浮空衰減與一次彈地；頭目不使用普通敵人的升空與彈地邏輯。這不是已全面驗收的無限連限制或 PvP 平衡系統。

## 測試與修改後重建

`tools/run_qa218.py` 重新建立內嵌頁，在三個獨立 Chromium 頁面執行回歸、相容性及 21.8 專項。`tools/smoke218.py` 使用鍵盤事件檢查 ZZX → 跳取消 → 空中 ZZX、方向連按、Shift 指令與 C 後立刻 F；截圖出自遊戲 DOM/Canvas。

編輯後依序執行測試、`tools/build_singlefile.py --output PLAY_OFFLINE.html`、鍵盤 smoke、`tools/update_checksums.py`、`tools/check_release.py`。未重建的 PLAY_OFFLINE.html 不會自動讀取修改過的 data/js。
