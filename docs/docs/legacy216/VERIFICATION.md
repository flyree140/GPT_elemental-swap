## 啟動與效能觀察

測試在容器的桌面 Chromium 執行。企業瀏覽器的直接導航政策限制下，測試器把原 `index.html` 載入頁面，以本地 HTTP 供應相對資源；另測完全內嵌 HTML，不需網路。沒有真的登入你的 GitHub 發布，也沒有冒稱實體手機測試。

停用隱藏舊 atlas 的預繪後，核心啟動取用 **88 張**既有圖片；其 RGBA 像素量估計 24,798,564 bytes，另加整體人物表 8,847,360 bytes，合計約 **32.1 MiB**。這不包含 Canvas、遊戲物件、GPU 驅動與瀏覽器本身，**不是 RSS／總記憶體數據**。遊玩到其他區域時會載入更多素材。

畫質採原有平衡／省電／清晰三檔，平衡模式限制內部渲染像素並在持續慢幀時降低解析度；HUD 以 10 Hz 更新。短測試的逐幀數據保留在 `reports/delivery.json`，包含開場、選單與首次素材繪製的慢幀，不用來宣稱任何裝置保證 60 FPS。視覺快取有上限，尚未做長時間裝置級記憶體剖析。
