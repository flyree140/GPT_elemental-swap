# 21.6.0 人物、地圖與效果

## 玩家

來源為使用者提供並確認的 A07 動作／人物設計圖。`assets/entropy216/hero.webp` 是 1280×1728 的透明整體姿態表；`js/hero216_manifest.js` 選用 59 格，分成 idle / walk / run / jump / dash / hurt / recover / cut / cross / spin / cast / finish 共 12 組。格子不等於新繪製的動畫張數，也不是所有組都含同樣多的格子。

待機、步行、跑步、躍起／下落、衝刺、受擊／恢復、近戰與施放按照實際角色狀態取樣。走跑依移動距離推進；近戰畫格按前搖、命中和收勢階段取樣。玩家渲染不再將上臂、下臂、大腿、小腿分開轉動；刀與手保留在同張整體姿態裡。技能場與軌跡則由程式繪製。

來源格子尺寸不大，攻擊／施法可用姿態數少，部分效果相連的格子已排除。因此仍不等於 Afterimage 或其他商業作品完整的高解析逐格動畫。NPC 仍使用前版共用骨架，並不是全世界人物都重畫。

## 可遊玩場景

十二種環境素材沿用上傳的前版圖檔及布局。序章使用原房間地形，新增實際通道連結、44 個法則結構與 12 個記憶菱形。M 地圖從 `nInit().mask` 空洞／實心資料、房間座標、真實通道生成，選取僅追蹤、不偽裝成可瞬移的插畫。

原概念美術總覽不再出現在可操作地圖選單，舊 atlas 的隱藏繪製亦停用，避免啟動時解碼所有遠景。`previews/` 全部為此遊戲程式的執行截圖。

## 技能與怪物

刀弧、交叉線、環陣、重力井、預警框、藤／冰／岩台由當前碰撞、攻擊座標與技能時序生成，使用小圖緩存及有上限的效果佇列。沒有從 Afterimage、Dimraeth 或艾爾之光提取商業貼圖、角色或招式資源。

時間魔物使用既有 boss 造型家族，空間魔物使用既有 bird 造型家族，新增獨立 AI、鎖定線、真／假位置與破綻期；不是兩套全新逐格怪物圖。

## 重新建立人物表

`python tools/build_hero216.py /path/to/A07.png`。需要 `tools/requirements-art.txt` 中的 Pillow、NumPy、SciPy。原大張來源不再重複打包進遊戲，來源雜湊與裁切結果在 `assets/entropy216/provenance.json`。遊玩本身不需要 Python 或這些套件。
