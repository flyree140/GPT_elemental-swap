## 直接部署 GitHub Pages

解壓縮 ZIP，把**裡面的全部檔案與資料夾**放進儲存庫根目錄，讓 `index.html` 與 `js/`、`assets/` 同一層。到 **Settings → Pages → Source: Deploy from a branch → main → /(root) → Save**。不需額外 Build command。完整說明見 `DEPLOY_GITHUB_PAGES.md`。

不要只上傳 ZIP 本身，也不要只覆蓋單一 JS。更新前先從遊戲選單匯出存檔；舊發布資料夾備份後完整替換，避免繼續保留舊的大圖與離線 HTML。瀏覽器重新整理後，標題應顯示 **21.6.0**。

本機可執行 `START_LOCAL.bat`（Windows，需 Python 3）或 `python3 tools/start_server.py`。只想單獨開檔試玩，可用另附的 `ESV21_6_0_PLAY_OFFLINE.html`；它為避免容量重複而不放入 ZIP。

## 從哪裡開始

起點「潮息避難所」右側有**連段練習晶核**。接近金色記憶菱形按 **E**；開 **L** 選擇流派並看每招用途，然後沿 **M** 地圖的金色序章通道走。不是所有路都要求先完成房間任務；完成條件後再回菱形收束即可。

第一組可練習的連段：**Z Z → V 挑空 → ↑ S 發射 → D 空中換位 → 空中 Z → N 收尾**。先用 **0** 發射引力錨，把小敵聚起再接招。大敵不會被無限吸上天。

## 元素、法則、故事

十元素有不同的命中與換位效果。0 引力真的推進怪物位置；冰、岩、藤可生成可站立踏台；水與雷導電、水與藤催生、火消耗凍結／根系爆裂；光暴露弱點，影留下改變追逐方向的誘餌。水／風場內按 ↑ 上升。

換位共用容量初始 1、Lv.2 為 2、Lv.3 以上為 3；每 1.25 秒回一格，空中照常回充。收束第 1／3／6 段記憶會保證元素至少達到 Lv.1／2／3。失敗不消耗、不刪除錨點；實心障礙、未開機關與距離安全檢查仍存在。

當下、過去、未來、大重力、向量反轉、彈力、裏層、真菌、消逝共九種法則。序章新增 44 個有真實碰撞的法則結構。既視感從法則名單中移除；F 只重播，傷害係數為 40%，不重複發獎、不恢復血量、不重置冷卻。

玩家是「墒」，調用無序元素收束 12 段記憶。非避難所中，時間／空間操作會累積失控；達 100 後先有 4 秒預警，再出現具有鎖定、出手、破綻期的魔物，同時最多一隻。擊退使對應失控下降 45，並給 60 秒緩衝。最後「歸零觀測台」可主動召來尚未擊敗的時空魔物；集齊前 11 記憶且擊敗兩種魔物後收束最後記憶。序章結束後仍能探索舊世界。

## 本版範圍與素材

**保留原有 300 個房間；這次新增的完整記憶流程與法則路線集中於前 12 房。** 其餘房間沿用原有關卡內容，會共用新的戰鬥、元素、HUD 與失控系統；不是 300 房全部重新手工製圖。

角色取自你批准的 A07 整體人物姿態，整理為 **59 個被選用的畫格、12 組姿態**，不再將玩家的肘、膝、手腳獨立拼貼。這些是既有美術的裁切、透明化與時序重整，**不是 59 張全新逐格手繪**。NPC 與部分敵人仍共用原素材家族，兩種時空魔物新增行為和預警效果、沿用既有造型家族。詳見 `ART_AND_ANIMATION.md`、`ASSET_SOURCES.md`。

遊戲按 M 只開由實際世界座標與碰撞繪出的地圖。`previews/` 僅是實際執行畫面的截圖，不是另一套不可遊玩的美術地圖。
