## D 解謎要素【規劃】

# 5. 怪物 / A 魔物、B 生物、C 頭目

## A 魔物：失序凝成的攻擊意圖

【沿用】charger、scatterer、mimic 等行為可作基礎。【規劃】魔物分類要以「違反哪條世界規則」決定設計：重播攻擊、折疊距離、竊取重力、偽裝指令等。不能所有魔物都只是換色史萊姆。

| 名稱／原型 | 行為與玩家回應 | 製作狀態 |
| --- | --- | --- |
| 潮晶礦甲獸／charger | 紫晶甲先亮起再衝撞；背側回復期可破勢，雷弱點只是加分而非唯一解。 | 外觀參照使用者圖；完整專屬 AI／動畫規劃。 |
| 夢脈水母／shocker | 脈衝前收縮觸鬚；從上下空隙穿越或風偏移。 | 既有電擊原型可用；專屬動作規劃。 |
| 指令擬態箱／mimic | 依頭上指令解除護甲，鼓勵 ZZX、↑X 等。 | 沿用既有指令機制；美術仍需精修。 |
| 斷頁巡禮者／chrono 概念 | 重播一次先前攻擊；第二次位置相同，教玩家等待再進。 | 新怪規劃，非現版獨立 type。 |

## B 生物：不是看到就必須殺

【規劃】潮殼蟹會搬運發光礦粒，幫玩家找到隱藏縫隙；帆翼鰩逆風滑行，提示風場方向；菌角鹿靠近水床，提示水藤共生。攻擊它們不產生必需材料，避免玩家為完成圖鑑被迫清空每個環境。

## C 頭目：對已學機制的整合考試

【沿用】既有 sentinel 等頭目原型與破勢條；衍生怪物名稱不代表每一個都有獨立三階段美術。【規劃】潮鐘守望者：一階鐘擺／破橋，二階水位／雙岸，三階光辨真身／換位回岸。每階只加一個主變數，保留可識別前搖與可利用收招。

頭目失衡時開輸出窗；不以長時間無敵或強制反傷懲罰正常進攻。控制技能對頭目轉為短緩或破勢，不能永久挑空。死亡只掉落一次，讀檔、離房與重入都需有一致狀態。

## 和劇情／經濟的關聯

序章收束需要兩種魔物都被擊退；觀測台可啟動儀式，讓未完成種類透過預警出現。離開太遠可使魔物失去定位並退去，這不等於擊殺，也不能提供擊殺記憶與獎勵。

【新增】有效擊殺接旅途 XP 與材料；訓練目標不給獎勵。同一個體加 reward217 避免重複結算。【規劃】失控魔物掉落稀有「定序核」，用於劇情分支與高階工坊，需另設限量／保底與存檔。

## 完整製作所需

兩種魔物目前基於既有怪物的行為與渲染族群，不等於已完成參考圖中的兩套高精細頭目。正式素材需有待機、巡視、預警、進攻、受擊、失衡、死亡完整影格；位置鎖定的線條與傷害事件必須同源。

# 9. 劇情 / A 故事

## 核心矛盾

世界把「不願失去」誤寫成「不准結束」。死亡的守橋者每天重新站起，沈船總在遇難前一刻復原，城市不斷為每個可能的人生增築新街。墒能讓循環停止，卻逐漸發現：被解除的世界中，仍有真實感受過痛苦與愛的人。

故事不把「回歸虛無」簡化為殺光所有人。真正的問題是：是否有權替他人決定終點？保存記憶與保存永恆重複的身體，是否同一件事？玩家以解謎、收集與戰鬥接觸不同答案。

## 現版可玩序章【沿用】

潮息醒來 → 學會出手、聚敵與換位 → 看見根系在不同時間重生 → 以既視感重播而不回到過去 → 穿過裏層 → 理解光的顯影 → 在觀測台面對時間與空間魔物 → 收束第十二段記憶。

## 完整主線篇章【規劃】

| 篇章 | 事件 | 玩家行為與主題 |
| --- | --- | --- |
| 第一章：裂縫的海岸 | 重播的沈船與等待家人的避難者。 | 學會收束循環，不抹去證言。 |
| 第二章：記憶的產業 | 紅鏽城以重複一天維持工廠運轉。 | 決定先保留哪一段必要供能，避免解放變成餓死。 |
| 第三章：共享的夢 | 菌核根網保存無數個體的感覺。 | 辨別共同記憶與被強迫加入的意識。 |
| 第四章：誰的原本世界 | 影鏡與海底紀錄顯示多個起源。 | 不再假定只有一個版本的人值得存在。 |
| 終章：留下什麼 | 天空觀測器能強行清零，也能有限封存。 | 結局由先前任務與被保存的證言決定，不只最後按鈕。 |

敘事規格：主線台詞短，完整記憶可在圖鑑重讀；關鍵資訊至少由環境與對話各提供一次。玩家跳過對話仍能知道下一個操作目標，不應靠閱讀長篇設定才能移動。

## 條件如何實作才可維護

以具名旗標記錄事件，例如 witness_tide、pact_fungi、power_metro、memory_archive，而非在多個檔案散放「任務數大於 7」等隱藏魔法數字。最後選擇前顯示可預見的代價，但不一定直接透露所有劇情畫面。

結局檢查應是純資料函數：輸入旗標回傳可用結局；存檔、讀檔、重看和通關後自由探索分開。未達條件要給可追溯提示，避免玩家玩到最後才知道早期不可逆的對話漏了一句。

【規劃】二周目主要提供新的敘事視角與路線，不用單純加敵人 HP 取代內容。需要先把第一輪的原型做完整，再談二周目。

# 10. 寵物 / 收服與共同行動

【界線】現有靈契塑形的 s.pet 是職業召喚與協擊，不等於已完成全世界野生寵物收服。本次沒有新增並驗證下列通用收服／培育流程；以下為續作規格。

## 收服【規劃】

遇見 → 圖鑑觀察 → 滿足安撫條件 → 使用封存匣／契約 → 命名並送往避難所。安撫不是打到殘血的唯一方法：潮殼蟹交還遺失礦粒、帆翼幼鰩恢復氣流、夢燈水母關閉刺耳裝置。失敗生物離開或暫時戒備，不永久消失。

| 寵物 | 探索用途 | 戰鬥用途與限制 |
| --- | --- | --- |
| 潮殼蟹 | 指出附近可挖掘潮晶，不自動清空整張地圖。 | 偶爾推開地面小彈；無法擋頭目重擊。 |
| 夢燈水母 | 照亮低光區與藏匿刻文。 | 單次標記一個近敵；和光元素作用不同。 |
| 帆翼幼鰩 | 提示風向，可提供一次微小修正。 | 短時減緩下降，不增加換位容量。 |
| 菌角幼鹿 | 靠近可催生的位置發出反應。 | 消耗場域能量才給微量支援，不能無限補血。 |

## 攜帶、成長與指令【規劃】

同時一隻跟隨寵物；靈契職業召喚另有上限。指令為跟隨、停留、互動、召回，避免寵物擋住跳躍與投射物。成長解鎖新的行為與外觀，不把探索提示變成自動解謎。

存檔至少需要 speciesId、individualId、name、bond、unlockedActions、equipped；路線尋找失敗時安全回到玩家身旁而非掉進無底洞。新寵物必須包含圖鑑、收服任務、動畫、避難所棲位與效能上限，不是只在菜單加一個按鈕。

# 11. 等級

## A 成長系統

【新增】旅途等級 = min(30, 1＋floor(XP/80)＋floor(已收束記憶/3))。普通擊殺 8 XP、頭目／失控魔物 32 XP；訓練不給 XP。旅途等級用於顯示和等差修正，不會在本版自動每級加血、解鎖所有技能或多一格換位。

| 成長項 | 現版狀態 | 後續方向【規劃】 |
| --- | --- | --- |
| 職業能力 | 六職業、30 主動、第一層二選一。 | 以訓練與章節任務解鎖第二／第三層。 |
| 元素 | Lv.1～3 容量與場域部分成長。 | 各元素戰鬥／探索分支；共用消耗不變。 |
| 基礎能力 | 沿用原進度與職業能力，未新增自動每級全屬性成長。 | 生命／移動／資源分別選，保持操作重要。 |
| 連段 | 29 組可配置指令，不逐級限制全部招式。 | 完成操控課程解鎖技巧變體，而非基本操作。 |

## B 強化分支選擇

【新增】當前避難所重配免費、一次每職一個第一層分支。【規劃】每個分支先問「鼓勵哪一個行為」，再決定數值。示例：破勢路線加重攻擊代價，空戰路線減地面效率，延遲路線提高失手風險。不能所有選擇都同時提高傷害、範圍、速度與安全。

## C 打怪物減傷（等級限制）

【新增】敵等高於玩家時，玩家對該敵的輸出倍率 = max(0.55, 1－0.06×等差)。低於或同級不套此懲罰；不是角色受到的傷害降低。高 3 級為 0.82，高 5 級為 0.70，高 8 級降到保底 0.55。

目的是讓越級有風險而不是完全鎖死探索。此曲線是原型數值，尚需實際擊殺時間／死亡率測試。新生怪可指定 level；大多沿用怪物依章節位置推導，整個 300 房間的最終等級配置尚未手工平衡。

玩家眼睛的第一層：自己、落腳處、敵人預警。第二層：HP、換位餘額、目前法則與技能冷卻。第三層：任務、世界進度、素材。開戰時不能讓圖鑑卡與裝備說明遮住第一層。

# 13～15. 補充分類 / 製作規範與驗收

## 13 音效、動作與無障礙【多數為後續製作】

輕擊用短起音與較少低頻，重擊使用蓄勢呼吸、厚實接觸聲與較長尾音；打空、擋住、命中、破勢必須不同。設定需有音樂／效果／介面獨立音量、減少閃光、震動／晃動強度與可讀字級。現版的基礎音效不等於已完成這套音訊規格。

## 14 經濟、難度與掉落

記錄新手完成首個循環所需時間、每種裝備的選用率、越級擊殺時間與失敗原因；不要只看總傷害。主線資源保底，探索給不同解法或圖紙。新增裝備前先定義它取代哪件、在哪種敵人面前更好、在哪種情況要付出代價。
