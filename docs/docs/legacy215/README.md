# 澄界 V21.5 — 連續骨架・空中換位

此資料夾是可獨立執行的完整版本，不是差異補丁。以你提供的 V21.4.1 ZIP 為基底，保留 300 個房間、15 個職業、90 個技能與原有探索系統。

## 直接開始

解壓縮後開啟 `index.html`。所有美術、程式與樣式都在資料夾內；不要只搬走 HTML。若瀏覽器限制本機檔案，Windows 執行 `START_LOCAL.bat`，macOS/Linux 執行 `python3 tools/start_server.py`。啟動器需要 Python 3，不需 npm 或其他遊戲引擎。

另有獨立提供的 `ESV21_5_PLAY_OFFLINE.html`，它本身已包含遊戲與素材，可單獨開啟。為避免同一份美術在 ZIP 裡重複佔空間，該單檔版沒有再次塞入本 ZIP。`python tools/build_singlefile.py` 可由這份完整原始碼重新產生 `PLAY_OFFLINE.html`，不需要 Pillow。

## 空中換位操作

| 按鍵 | 功能 |
| --- | --- |
| ←／→ | 移動 |
| Space | 跳躍 |
| Shift | 衝刺 |
| 1–0 | 發射對應元素；已有目標時，再按同數字換位 |
| D | 立即對目前元素的目標換位；沒有目標時先發射 |
| S | 往目前方向重射錨點，不補充換位次數 |
| 方向鍵＋發射 | 八向瞄準，包含正上方、正下方 |
| 滑鼠右鍵 | 無目標時往游標發射；已有目標時換位 |
| Z／X／Y | 原有普通攻擊與連段 |
| C／V／B／N／F | 原有五技能槽 |

換位不需要落地、不需要站在指定平台，也不需要站穩等待。子彈目標優先於附近被標記的敵人。HUD 虛線框顯示實際預定落點；S 可以重新瞄準。

保留先前要求的等級容量：Lv.0／1 為 1 次，Lv.2 為 2 次，Lv.3／4 為 3 次。十種元素共用已消耗次數，避免換元素或重射就補滿。每 1.25 秒遊戲時間回復 1 次，空中、移動中也回充；暫停與選單不推進回充。仍有實心牆、未開啟機關門及最大作用距離等安全檢查；不是任意穿牆或無限連續傳送。失敗不扣次數、不銷毀錨點。大型頭目未 BREAK 時允許移到其側邊，BREAK 時才完整交換。

手機有獨立「換位 D」「重射 S」按鈕，與原技能列分開。

## 這版修改了什麼

**容量與載入：** 移除舊大型人物動畫表、重複離線包及舊預覽；保留必要相容美術。素材改為內容雜湊 WebP，裁除人物／武器透明空白。啟動先載入核心美術，其他圖鑑與遠景按需載入，不再一次解碼全部舊圖。

**動作與關節：** 保留原有角色畫風，以連續紋理網格連接膝、肘及手腳。固定骨長，以位移推進步態；重新編寫走路、跑步、跳躍、下落、衝刺、受擊、倒地、起身與各種攻擊姿態。斬擊、刺擊、重斬等動作對齊真正傷害脈衝；武器從真實刀柄位置固定在手掌，避免漂浮與長寬比例被壓扁。這是連續骨架動畫，不是逐格重新手繪或外部遊戲的動畫素材。

**渲染：** 玩家與殘影重用小畫布；殘影繪製在人物後方。刀光沿實際刀尖軌跡產生。保留空間碰撞查詢、地形快取與三段畫質；背景由原先每 180 ms 更新改為平衡畫質約 33 ms。效能設定不刪除技能傷害、召喚物或技能平台。

## 更新舊版／GitHub Pages

先備份，再用此資料夾完整替換舊發布資料夾；不要把新檔案疊在仍含大型舊素材與 `PLAY_OFFLINE.html` 的目錄上，否則磁碟容量不會真正減少。

上傳本資料夾的**內容**到 GitHub Pages 所選的根目錄或 docs 目錄，讓 `index.html` 與 `js/`、`assets/` 位於同一層。沒有 API 金鑰、外部素材 CDN 或建置步驟。

原有進度儲存鍵未改名，也沒有加入清空存檔操作。建議先在遊戲內匯出存檔；換網址、換瀏覽器或改用本機 HTML 會是不同儲存空間。快取有疑慮時可強制重新整理，但不要為了更新而刪除網站儲存資料。
