## 修正

- 不再啟動時同時建立並解碼 516 個舊圖片項目。初始化先描述素材路徑，真正讀取時才建立 Image；同 URL 共用圖像物件。
- 去除舊 art20 大型人物動畫表與舊稀疏 rig 圖，保留新的緊密紋理、完整遊戲資料與必要相容素材。移除重複的離線大檔與舊預覽。
- 武器依 alpha 邊界裁切，獨立設定刀柄座標與等比例縮放，修復原先刀刃變細、武器偏離掌心的問題。
- 膝／肘以共享頂點的連續紋理變形呈現；沒有把兩截手腳各自旋轉後硬接。
- 步幅依實際位移推進；起跳、下落、落地、衝刺與攻擊有短過渡。攻擊前搖／命中／收招對齊真實 hit pulse，不只循環播放同一個揮手動作。
- 小畫布與三份殘影緩衝重用；移除每個動畫時間鍵都新增整張畫布的角色快取策略。
- 移除站穩 0.6 秒且距上次換位 2 秒才恢復的條件。保留 1／2／3 等級容量，改成空中也能每 1.25 秒回充一次。
- 新增 D 即時換位、S 重射、正上／正下瞄準、最新錨點優先、落點預覽與失敗時保留次數／目標。
- 修正錨點碰到平台後不停延長存活時間，避免無限殘留。
- 修復空間查詢遺失衰變平台失效條件；衰變平台不再永久留在地形快取中。
- 背景更新改為 16／33／80 ms（清晰／平衡／省電）；保留固定時間步模擬及最多三步追趕，限制長時間卡頓後的追趕負擔。
