## 容量與圖片負載

原 ZIP：55,903,915 bytes；原發布資料內同時含 23,269,526 bytes 的嵌入式離線 HTML 與另一份素材，還有舊預覽。新版主 ZIP 不再包含這份重複的離線檔，試玩單檔另外提供。

原啟動路徑列舉 516 個圖片物件，寬×高×4 的 RGBA 像素量加總約 568.57 MiB。新版核心就緒時為 108 個唯一圖片、29,899,160 bytes（約 28.51 MiB）；測試中的一般跑動／連段後為 109 個、30,423,448 bytes（約 29.01 MiB）。這是圖片像素量估算，不是瀏覽器總 RAM 或 GPU 記憶體的量測，原版重複 URL 的解碼也可能由瀏覽器共用。

全部相容圖片刻意強制解碼時約 242.91 MiB。按需載入降低的是一般啟動與遊戲路徑負載，不宣稱看完所有圖鑑後也只佔 28.51 MiB。

Headless Chromium、桌面 1440×900 CSS 視窗、平衡畫質、內部畫布 1145×716。暖機後採樣正常遊戲更新，309 個畫格中：中位數約 16.7 ms、95 百分位約 16.7 ms、最長約 33.3 ms；平均畫格間隔約 16.88 ms。每畫格遊戲程式 CPU 更新加渲染的平均量測約 3.98 ms、95 百分位約 6.0 ms。詳細原值在 JSON。

## 重現

`python tools/check_release.py` 驗證發布依賴與雜湊。`python tools/build_singlefile.py` 產生單檔版。`tools/qa215.js` 可在**備份後的獨立測試工作階段**載入並執行 `runQA215()`；它會移動角色、改變測試中的進度與停止遊戲迴圈，不應在正式遊玩存檔中直接執行。
