# 動作與美術實作

V21.5 保留上傳版本的角色設計與配色，改用裁切後的緊密圖集。每條手／腿是完整紋理帶：關節兩側的網格共享頂點，骨長固定為大腿 35、小腿 38、上臂與前臂各 27（渲染用局部單位），再以等比例轉到遊戲世界。

腳掌的支撐期、離地回擺、髖部位置、上身前傾分別控制；走跑動畫由位移而非任意固定動畫速度驅動。攻擊使用前搖、命中、跟隨動作及收招關鍵點，依 `pulses19` 把命中姿態對齊實際攻擊時刻。短時間過渡用於避免姿勢切換的瞬間跳變，不替代遊戲攻擊判定。

武器有各自的 alpha 裁切範圍、掌心握點、大小與旋轉補償；槍械與長柄武器不再使用同一個被壓扁的矩形。手掌覆蓋在握柄上。刀光取樣目前與先前刀尖位置，不在攻擊結束後另外播放與手臂無關的大圓弧。

披風使用同配色的連續曲線表面，避免原圖殘留四肢造成重影。這是重新組織的連續骨架／網格動畫；並非每一格、每一職業都重新手繪。原始素材來源與限制保留在 `ASSET_SOURCES.md`。

實作參考：MDN「Optimizing canvas」關於離屏重用與減少重繪的說明；Spine「Mesh attachments」關於紋理網格與變形的說明。未加入 Spine 執行庫或其商業素材。
