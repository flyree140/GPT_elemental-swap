## 內容完整性與實際數量

300 個房間 ID／名稱唯一，175 個新地點都在邊界內。世界共 398 段不重複連線，圖結構由 r00 可抵達所有 300 地點。原回歸另抽驗每段通道首／中／尾為通行空間，合計 1,194 點；底床與新增地點返回梯道存在。沒有全世界救援水帶或房間出口傳送。

每個新生境七地點、兩原生種、一地方裝備；共 25 生境、100 非王研究區、25 前哨、50 新王庭。100 個研究條件經 fixture 指定其條件後呼叫真實 fOperate 均完成；不是每處都由玩家手動步行完成。

50 新原生種各有領域王；49 舊原生種也有可互動召王碑。99 新王種都能生成並在半血進第二招式階段。所有新材料可由實際採集或掉落取得，33 新配方成本只指向有效物品。所有新機關與採集點不埋入實心凸起。

33 個新配方實際扣除材料，藍圖與工作台條件有拒絕測試；三工具槽不會無提示替換第四件。八消耗品有數量消耗與零庫存拒絕測試。普通死亡去重、75 秒再生；王種不重複召喚、死亡後 120 秒恢復皆有檢查。

## 實測中修正的問題

V19 儲存曾覆蓋 V18 研習保護，已改為研習快照；原採集紀錄上限 500 不足 678，已擴大並保留安全鍵過濾。補氧防具先補氧再更新傷害，避免零氧仍扣血。原根斧不比基礎束縛更長已改 3 秒，與文字一致。移除不存在的新怪物 PNG 請求。

配方 footer 繼承舊面板 sticky 規則導致按鈕跨卡重疊，已限定為卡內正常排版。手機橫向小地圖移至血條旁，不占左下搖桿。匯入舊版本會正確清除 V19 優先讀取，並備份原檔。

## 測試環境與限制

本環境 Chromium 有 top-level 網址導覽限制；沒有繞過它，使用 set_content 載入由正式原始碼產出的單檔 HTML。多檔 URL 以 HTTP 逐檔請求驗證，不冒充在真實 GitHub origin 上完成整站導航。

只有指定 --storage 的三组核心／儲存資料測試使用記憶體 localStorage 替代物，測試的是真的 JSON 序列化／遷移／欄位保留，不是原生儲存跨重整。正式 PLAY_OFFLINE/index 與其他控制、介面、截圖測試都沒有此替代物。瀏覽器不允許儲存時遊戲可繼續跑，但要自行匯出備份；本機 file、Safari、隱私模式與真實部署持久性仍需實機檢查。

手機檢查為 Chromium 896×414、390×844 觸控模擬；桌機為 1600×1000、1440×1000、1280×800 相關測例。不是實體 iPhone、Android 或 Safari 驗證，也沒有承諾低階手機固定幀率。

300 地點使用 12 組共享地形構件與 40 種任務類型；物種使用 19 種行為組合。不是 300 個完全不重複的精製美術關卡、149 個獨立 AI，或百小時內容驗證。圖結構連通、取樣路徑與 fixture 通過，不能替代每个角落的人工實玩。

九規則、十五職與裝備互動仍可能需要實際遊玩平衡。參考圖美術全套沒有硬改。新 V19 狀態未完成多人同步，交付以單人為準。
