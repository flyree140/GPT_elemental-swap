# Elemental Swap V19｜生境圖譜

**可直接部署的單人 2D 橫向卷軸網頁遊戲。** 入口為 `index.html`；離線版為 `PLAY_OFFLINE.html`。不需 npm、後端、API 金鑰或登入。

## 先玩

電腦可直接開 `PLAY_OFFLINE.html`。正常網站使用 `index.html`；手機建議開部署後的 HTTPS 網頁，再點上方「手機模式」。

方向鍵移動，空白鍵跳躍，Z／X 普攻；C／V／B／N／F 是固定五個技能，Q 是職業機構。技能按下不立即施放，放開施放；一般長按門檻 0.65 秒，狙擊 0.9 秒。數字 1–0 首次射出元素、再次按同鍵換位。M 地圖、O 遠征工坊、L 技能、J 世界規則、T 實作教學、E 互動、G 使用指定補給。

第一次請按 T 做八階入門，再選一個職業研習。普攻放開方向鍵就是原地出手，不會暗中突進或附帶射擊。

## 本版重點

300 個地點與 398 段實體連接；新增 25 種生境、175 個具名地點。大地圖有「你在這裡」、座標、定位、縮放、拖曳、搜尋、步行路線；小地圖顯示真實局部地形與元素錨點。新增 50 原生種及 99 對應領域王（50 新種對應、49 舊種對應），遭遇式圖鑑共 207 條，不含訓練靶。

新增 25 件地方裝備、8 種消耗品；全遊戲共 61 配方、63 類素材。XZ 回拉、ZZX 上挑、XXZ 破甲、ZXX 束縛、XZX 反彈，ZZZ 三段定點連刺；90 技能基礎冷卻 1.15–4.8 秒，普攻命中縮短最久的技能冷卻，揮空不回復。

十五職、十五族、固定五槽、九世界規則、四層元素 A／B 疊加、連續地層與舊避難所系統保留。

## 部署 GitHub Pages

將本資料夾的**內容**上傳到 repository 根目錄，第一層直接有 `index.html`、`js/`、`assets/` 和 `.nojekyll`。Settings → Pages → Source 選 **Deploy from a branch** → 選 **main / (root)** → Save。不要只上傳 ZIP，不要只覆蓋幾個 JavaScript。

所有核心依賴使用相對路徑，可放在 repository 子路徑。更新後左上顯示 **V19 · LIVING ATLAS**。交付包已完成封裝；未登入你的 GitHub 實際發布網站。更多見 [GITHUB_DEPLOY.md](GITHUB_DEPLOY.md)。

## 存檔

更新前先在舊版 L 工坊匯出 JSON。V19 的儲存鍵是 `es19_progress`；匯入會備份原 V19，舊 V17/V18 可遷移。研習借用配置不會寫回探索配裝。請定期匯出，尤其是隱私模式與本機 file 開啟。

## 內容邊界

這是整合可玩的擴充原型，不是百小時／商業遊戲完成驗證。300 是實際地點數，不代表 300 套獨立美術；新區共享 12 類地形構件、40 種任務類型及 19 類敵人行為。不同物種有外形、數值、主副攻擊與掉落，但不是 149 套獨立 AI。
