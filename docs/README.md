## 既視感 F

按下 F 時，重演**按下前 3 秒**的普攻、技能攻擊、投射物、當時已發生的持續傷害與成功換位。殘影依原本位置、朝向、動作與時序行動；不是只重複最後一招，也不是只有無傷害的拖影。已取消舊版最多 48 筆的截斷。

傷害沿用原版 **40%**。本體可以繼續操作，不會被殘影的換位拉回舊座標，也不再消耗第二次技能冷卻或換位次數。殘影不會被自己再次錄製；不重複吸血、回充或新增一整輪燃燒反應。

**按技能後立刻按 F 也有處理**：在記錄窗內已起手的攻擊，其尚未發生的原本後續判定會補完。這時收尾可能稍超過 3 秒。第 3 秒剛重演發射的投射物會繼續飛行至命中、碰牆或原本壽命上限，不會直接被刪除。

持續場只重演記錄窗內的傷害節點，不重建新的完整持續場。沒有攻擊的輔助／切換招式只保留施放記錄，不再發一次回血、護盾或配方切換。既視感本身不重演。

## 先練這幾條連段

每個字母代表一次按鍵，並非按住自動連續。`→→` 表示快速按兩次右方向；向左同理。

| 按法 | 作用 |
|---|---|
| Z → Z → Z → Z | 地面連斬，最後擊退收尾 |
| Z → Z → X → Space → Z → Z → X | 挑空，命中後跳取消，空中雙斬接墜擊 |
| Z → X → Z → X | 滑步切入，雙環聚敵，再終斬 |
| X → X → Z → Z | 重擊轉破甲，再挑空 |
| →→Z → X，或 Shift＋Z → X | 衝刺突刺接升空，可再接空中攻擊 |
| 空中 Shift＋Z → Z → X | 空中突進、返刃、下墜收尾 |

↑＋X 主動升空；空中 ↓＋X 向下劈。命中後可跳躍／衝刺取消；多段攻擊要完成最後一段。終結技保留收招。低空下劈落地會結算衝擊，不會在碰地前直接消失。普通 Z 不強制位移。

共 **49 組獨立指令資料**。輸入基礎緩衝 0.28 秒、最多 3 次待接輸入；按順序處理，不用最後一鍵蓋掉前面。遊戲按 **H** 看連段表，按 **F8** 看真實判定框。訓練面板也列出全部指令。
