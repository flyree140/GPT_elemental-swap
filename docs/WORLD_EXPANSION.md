# 東境拓展

V9.1原有52房/71連線不刪也不搬。新增16探索房和10教場，總計78房/103連線。原赫利俄斯r48保留；e15是額外的哨兵AI變體，不是假裝新增獨立全套Boss AI。

| 房間 | 用途 |
|---|---|
| 東境渡口 (`e00`) | 渡口床鋪、食物與教場入口 |
| 鏽潮運河 (`e01`) | 水→雷：沿濕潤導線啟動共鳴爐 |
| 垂蔓貨井 (`e02`) | 把換位彈向上投，或乘鷹翔與鉤環上升 |
| 熄火鍛造室 (`e03`) | 冰→火：擊裂外殼後回到渡口捷徑 |
| 火爐中庭 (`e04`) | 三路交會；護甲與破勢教學 |
| 霧燈診所 (`e05`) | NPC 提供治療、專精點提示 |
| 銅鴞花園 (`e06`) | 藤→風：喚醒屋頂轉軸 |
| 倒懸書庫 (`e07`) | 光→影：揭露穿過書庫的隱藏門 |
| 風羽長井 (`e08`) | 飛行與移動技能的垂直支線 |
| 斷鐘避難屋 (`e09`) | 與工匠交換專精零件 |
| 磁雨列車 (`e10`) | 精英砲陣：讀預警，不要站在落點 |
| 凝晶暗窟 (`e11`) | 引力搬運／分支強化收藏 |
| 雙環試煉庭 (`e12`) | 環路與雙端爆發：新區域守衛 |
| 晴穹苗圃 (`e13`) | 高處收藏；返回診所的快速支路 |
| 觀星寄宿所 (`e14`) | 最後補給與十職研習院回程 |
| 共鳴鑄心 (`e15`) | 東境 Boss：熔鑄監察者；不取代 r48 最終哨兵 |

東境入口由雨幕舊城r13連至e00。中段可回r21，上段可回r42，並非單向長廊。M可看所有節點，尚未探索的房間保持暗色。

四座共鳴爐：鏽潮運河(水→雷)、熄火鍛造室(冰→火)、銅鴞花園(藤→風)、倒懸書庫(光→影)。首解各+3專精點；其中水雷、光影解除地圖上的實體研究門。
六個研究匣位於東境房間內，E開啟+4點；新功能神殿也沿支線配置，不把獎勵排成一長列。
新區沿用你喜歡的V9.1背景Atlas和平台語言，沒有替換成整齊高塔。
房間連通性以圖論測試驗證，不等同所有路線都已由人類徒步走完。沒有保證10/30小時遊戲時間。
