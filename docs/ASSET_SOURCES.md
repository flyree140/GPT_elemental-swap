# 素材來源與使用界線

21.7 新採用的美術來自本次使用者提供的七張概念圖與美術 RAR；21.6 原有資產留用。新檔案的來源、原圖 SHA-256 與加工方式記在 assets/atlas217/provenance.json。

加工包含裁切、壓縮、圖集透明碎片清理與動畫重排。沒有從 Afterimage、艾爾之光、Dimraeth 或 Dungeon Slasher 拆取遊戲素材。參考遊戲僅作使用者指定的設計與視覺方向。

使用者提供不等於已完成商業授權稽核。正式商用前請確認原始圖片、生成平台、舊包中素材及字體的授權與署名條件。本包不附系統字型檔；文件使用環境已有字型產生。

21.6 的原始說明留在 docs/legacy216/ASSET_SOURCES.md，供追溯。
