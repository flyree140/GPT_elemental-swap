## 沒有冒充已做的部分

- **不是全宇宙物理模擬。** 熵、量子、W 是遊戲規則名稱；不宣稱符合嚴格熱力學或量子力學。
- **不是所有舊牆都能隨意穿透。** 轉態材料及 A/C 平台以明確標記資料設定，主要在新增支環示範；原世界可使用通用殘影、投射物預測、凍彈、切片傷害規則，但不是逐面重畫85房的三套美術。
- **不是完美預測隨機 AI。** 精確可驗證的是新 attack plan 與既存直線／拋射彈體；沒有承諾未決定的隨機行為。
- **不是所有技能副作用錄影複製。** 傷害幾何／姿態／投射物可重播；新召喚物、治療、資源、冷卻重置不重播。原120技能本體仍可正常使用。
- **不是新美術世代。** 原像素角色、怪物、背景及避難所圖像未替換；新材料與視界提示用 Canvas 層製作。帕拉克斯重用已有哨兵 Sprite，行為和核心環新作。
- **不是已實測30小時商業產品。** 沒有新增此類時數承諾。
- **不是權威多人同步。** 網路沿用舊遠端玩家展示；濾鏡、敵人、機關、兩人共同回放等未做網路權威同步。本版驗收單人。
- **沒有替使用者部署到其 GitHub 帳號。** 交付的是完整可部署檔案，並非已上線的公開網址。
