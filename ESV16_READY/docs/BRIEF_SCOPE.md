| 來源提案 | V11 狀態 |

| Past／Present／Future 地圖 | 未在此版實作 |
| Soul Sight / Causality / Rule Sight | 未在此版實作 |
| Phaser 3 + TypeScript + Vite | 未遷移；保留 V10 原生 Canvas / JavaScript |
| 文稿中的 J/K/L 或鼠標操作 | 未覆蓋原方向鍵、Z/X、同元素鍵換位的使用者既有操作 |
