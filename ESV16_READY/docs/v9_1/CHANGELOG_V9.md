# V9 / V9.1 改動紀錄

- 重建 7 套人形職業 Sprite Sheet。

## V9｜Organic World Release

### 地圖

- 移除規律塔樓排列。

### 戰鬥

- Z／X Command 增加到 30+ 分支。

- 保留十元素同鍵換位。
- 安全落點搜尋避免嵌入平台。
- 元素速度保持 120～285px/s。
- 火、冰、水、自然、岩與引力會建立真正場域或碰撞平台。

### 收集與解謎

- 16 座功能神殿位於支線與能力門後。
